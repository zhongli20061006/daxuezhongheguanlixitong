# 智伴校园前端 UI 重构设计（现代学院风）

日期：2026-08-05
状态：设计已与用户逐节确认（共 4 节，全部批准）
范围：设计系统 + 布局外壳 + 核心页面优先，其余页面靠全局样式继承

## 1. 背景与目标

现有前端（Vue 3 + Element Plus 2.5 + 原生 CSS 变量）视觉上是典型的"AI 模板脸"：

- 蓝紫渐变（侧边栏、顶栏、登录页、问候横幅）
- 多强调色并存（蓝、橙、绿、紫）
- 自定义蓝 `#0EA5E9` 与 Element Plus 默认蓝 `#409EFF` 混用
- 白卡片 + 细边框 + 阴影的通用组件形态
- 三列等宽入口卡、胶囊徽章、系统默认字体

用户确认三个问题都要解决：整体风格模板化、具体页面难看、布局与信息密度不佳。

目标：

- 现代学院风：暖白纸面 + 墨色文字 + 单一深青绿主色
- 反模板化：无蓝紫渐变、单主色、有质感的排版与留白
- 不改变功能、接口、路由、业务逻辑
- 亮色模式（暗色模式留待以后，CSS 变量已为扩展预留）

## 2. 设计令牌

### 2.1 颜色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#F5F0E7` | 页面底色（暖米白） |
| `--color-surface` | `#FFFDF9` | 卡片 / 表面（暖白） |
| `--color-text-primary` | `#26221C` | 主文字（暖墨色） |
| `--color-text-secondary` | `#615B50` | 次要文字 |
| `--color-text-muted` | `#938C7E` | 弱化文字（占位、时间戳） |
| `--color-border` | `#E6DED0` | 分隔线 / 边框（暖沙色） |
| `--color-primary` | `#0F766E` | 主色 Teal：按钮、链接、导航高亮、统计图标 |
| `--color-primary-hover` | `#0B5F55` | 主色 hover |
| `--color-primary-active` | `#095047` | 主色按下 |
| `--color-primary-bg` | `#E7F0EE` | 主色浅底（标签、图标底、hover 背景） |
| `--color-success` | `#3F7D5E` | 成功（降饱和） |
| `--color-warning` | `#B07D2A` | 警告（降饱和） |
| `--color-danger` | `#B4493C` | 危险（降饱和） |

语义色浅底（`--color-success-bg` 等）使用对应的暖色浅调，保持同一灰阶家族。

原则：

- 全部删除蓝紫渐变与多强调色，全局只剩一个主色 Teal
- 成功/警告/危险仅在语义需要时出现，统一降饱和
- 阴影统一带暖灰调，不用纯黑高透明度

### 2.2 字体

- 中文字体栈：`PingFang SC, HarmonyOS Sans SC, MiSans, Microsoft YaHei, sans-serif`
- 数字统一 `font-variant-numeric: tabular-nums`（成绩、课号、时间、容量、统计数值）
- 标题：600–700 字重，`letter-spacing: -0.3px`，行高 1.25
- 正文：400 字重，行高 1.6
- 小标签 / 说明：12–13px，`letter-spacing: 0.08em`
- 页面大标题：22–24px；页面副标题：13–14px 弱化色

### 2.3 形状、阴影、间距、动效

- 圆角分层：容器 14px、控件 8–10px、内嵌元素 6px
- 阴影：暖灰调柔和分层阴影，卡片优先用底色深浅表达层级
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32 / 48；页面留白 24–32px
- 内容容器：`max-width: 1200px` 居中
- 背景：极淡暖色环境光晕（低透明度 radial-gradient），不是装饰性渐变
- 动效：所有交互控件具备 hover / active / focus 三态，transition 150–250ms；删除大面积滑入动画，改为轻淡入

## 3. 布局外壳

### 3.1 顶栏

- 56px 高，暖白底 `#FFFDF9`，底部 1px 暖沙色边框，无渐变、无重阴影
- 左侧品牌区：青绿圆角小方块标识 + "智伴校园"墨色字
- 右侧：通知铃铛、方形圆角头像（squircle，青绿浅底白字）
- 折叠按钮保留

### 3.2 侧边栏

- 暖白底，216px 宽，可折叠到 64px
- 导航项：墨色文字；hover 暖色浅底；当前页 = 青绿浅底 + 左侧 3px 青绿竖条 + 墨色加粗
- 去除渐变、去除逐项滑入动画（改为 200ms 轻淡入）

### 3.3 移动端底栏

- 暖白底、顶部 1px 细边框、当前项青绿高亮，与桌面侧边栏同一套视觉语言

### 3.4 页面主体

- 内容容器最大 1200px 居中，页面留白 24–32px
- 页面标题区：大标题 + 一行灰色说明文字，去掉"图标 + 底部横线"的旧写法
- 通知弹窗、用户下拉菜单等浮层统一暖白 + 暖沙边框

## 4. 核心页面

### 4.1 登录页

- 去掉深色渐变左半屏与 emoji logo
- 居中卡片式：暖米白背景 + 极淡环境光晕
- 卡片顶部：青绿圆角品牌标 + "智伴校园"标题 + 一行副标语
- 输入框 44px 高、圆角 10px、聚焦青绿描边；登录按钮通栏青绿
- "忘记密码"改为安静的灰色文字链接；页脚版权信息缩小

### 4.2 仪表盘

- 问候区：纯文字大标题（"下午好，李华"）+ 日期副标题，不再套卡片和背景
- 统计卡片：4 个一排，图标块统一青绿系浅底圆角，数字等宽对齐；语义色仅在真有含义时出现
- 主区非对称网格：左侧 2/3 今日课表（青绿左竖条列表），右侧 1/3 通知（hover 高亮、优雅空态）
- 快捷入口：从三张顶部渐变色卡片改为一行安静快捷链接，hover 变青绿，无渐变

### 4.3 AI 助手首页

- 历史会话面板：暖白底细边框；会话项 hover 暖色底、当前项青绿浅底；删除按钮 hover 时才出现
- Hero 区：青绿圆角品牌标 + 大标题 + 副标题；大圆角输入框 + 青绿发送键；快捷提示为浅青绿底文字块
- 消息区：AI 消息左对齐白底气泡，用户消息右对齐青绿底白字，错误消息暖红浅底，卡片类消息统一圆角轻边框
- 模型状态：在线 = 青绿圆点 + 文字；离线 = 暖灰/暖红

## 5. Element Plus 全局覆盖

通过 CSS 变量覆盖实现一套主题，15+ 个页面自动继承：

- `--el-color-primary` 全套换成青绿阶（含 light-3/5/7/8/9、dark-2）
- 表格：表头暖色浅底、行 hover 暖色、分隔线暖沙色、数字列等宽对齐
- 输入框 / 下拉 / 日期选择器：8–10px 圆角、暖沙边框、聚焦青绿描边
- 弹窗：14px 圆角、轻阴影、标题栏与底部栏暖色分隔线
- 标签、标签页、空状态、骨架屏、通知浮层：统一暖白 + 青绿 + 暖沙语言
